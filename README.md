# Snapdeal Men's Sports Shoes Web Scraping & Analysis

## Project Overview

This project is a Python-based web scraping and data analysis project.

The project collects men's sports shoes data from Snapdeal and analyzes product prices, discounts, ratings, reviews, and brands.

## Technologies Used

* Python
* Requests
* BeautifulSoup
* Pandas
* Matplotlib

## Data Collected

* Product Name
* Brand
* Selling Price
* Original Price
* Discount Percentage
* Rating
* Number of Reviews

## How to Run the Project

1. Install libraries:

   pip install -r requirements.txt

2. Run the scraper:

   python scraper.py

3. Run the analysis:

   python analysis.py

## Conclusion

This project demonstrates web scraping, data cleaning, data analysis, and visualization using Python.
